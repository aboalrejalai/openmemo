# Memo Session Archive: Raw Transcript Extraction

Turn raw, ephemeral AI coding agent transcripts into permanent, human-readable Markdown notes in the Memo vault under `sessions/_raw-<host>/`.

This archiving process preserves chat history and prompts across local tools without deleting or modifying original log files.

---

## Supported Agent Extractors

All extractor scripts reside in `.agents/skills/memo-session-archive/scripts/` and respect `MEMO_VAULT` or `OPENMEMO_HOME` environment variables.

### 1. Claude Code (`extract_claude_transcripts.py`)

Extracts conversation streams from Claude Code JSONL logs into Markdown:

- **Source path**: `~/.claude/projects/`
- **Output path**: `sessions/_raw-claude/<project-slug>/<session>.md`
- **Features**: Extracts user messages, thinking blocks, assistant prose, and tool results. Skips binary blobs and raw network payloads. Preserves subagent transcripts under `<session>/subagents/` when enabled.
- **Usage**:
  ```bash
  # Standard extraction
  python3 .agents/skills/memo-session-archive/scripts/extract_claude_transcripts.py --include-agents

  # Preview with dry-run
  python3 .agents/skills/memo-session-archive/scripts/extract_claude_transcripts.py --dry-run
  ```

### 2. Cursor (`extract_cursor_transcripts.py`)

Harvests agent interaction logs from Cursor project directories:

- **Source path**: `~/.cursor/projects/**/agent-transcripts/`
- **Output path**: `sessions/_raw-cursor/<project-slug>/<title>.md`
- **Features**: Parses user queries, assistant replies, and generates descriptive English slugs for notes.
- **Usage**:
  ```bash
  python3 .agents/skills/memo-session-archive/scripts/extract_cursor_transcripts.py
  ```

### 3. Codex CLI (`extract_codex_transcripts.py`)

Parses session logs, transcripts, and command history from Codex CLI:

- **Source path**: `~/.codex/` (`sessions`, `transcripts`, `history`, `projects`)
- **Output path**: `sessions/_raw-codex/<project-slug>/<title>.md`
- **Features**: Parses both JSONL event streams and JSON turn objects. If no transcripts exist on disk, it cleanly logs the checked locations and exits 0.
- **Usage**:
  ```bash
  python3 .agents/skills/memo-session-archive/scripts/extract_codex_transcripts.py
  ```

### 4. Gemini CLI (`extract_gemini_transcripts.py`)

Extracts single-document JSON transcripts generated by Gemini CLI hooks:

- **Source path**: `~/.gemini/` (`transcripts`, `sessions`, `projects`, `history`)
- **Output path**: `sessions/_raw-gemini/<project-slug>/<title>.md`
- **Features**: Extracts user prompts, `prompt_response` blocks, tool calls, and structured turns into clean Markdown. If empty, cleanly exits 0.
- **Usage**:
  ```bash
  python3 .agents/skills/memo-session-archive/scripts/extract_gemini_transcripts.py
  ```

### 5. Antigravity (*Bonus Adapter*, `extract_antigravity_transcripts.py`)

Extracts conversation history from Antigravity SQLite state databases:

- **Source path**: `~/.gemini/antigravity/conversations/*.db` and `~/.gemini/antigravity-cli/conversations/*.db`
- **Output path**: `sessions/_raw-antigravity/<host>/<title>.md`
- **Features**: Extracts UTF-8 text strings and step payloads from protobuf SQLite blobs using non-destructive temporary database snapshots.
- **Usage**:
  ```bash
  python3 .agents/skills/memo-session-archive/scripts/extract_antigravity_transcripts.py
  ```

## Bloat Cleanup (`cleanup_raw_markdown.py`)

Raw terminal sessions often contain terminal escape codes, ANSI colors, control characters, and huge base64 images that bloat the vault.

The cleanup script sanitizes extracted files in place while preserving all substantive text:

```bash
python3 .agents/skills/memo-session-archive/scripts/cleanup_raw_markdown.py --root sessions/_raw-claude
```

**What it removes:**
- ANSI escape sequences
- Directional formatting / bidirectional control marks
- NUL (`\x00`) and unprintable control characters
- Embedded base64 image strings (`[omitted-binary-or-base64]`)
- Oversized link lists and repeated terminal box-drawing borders

## Weekly Batch Run (`run-weekly.sh`)

To archive and clean all transcripts across all five hosts in a single command:

```bash
bash .agents/skills/memo-session-archive/scripts/run-weekly.sh
```

**Workflow executed:**
1. Runs Claude Code extraction (`--include-agents`)
2. Runs Cursor extraction
3. Runs Antigravity extraction
4. Runs Codex extraction
5. Runs Gemini extraction
6. Executes `cleanup_raw_markdown.py` over all five raw folders (`_raw-claude`, `_raw-cursor`, `_raw-antigravity`, `_raw-codex`, `_raw-gemini`)
7. Displays a summary `git status` of archived notes
