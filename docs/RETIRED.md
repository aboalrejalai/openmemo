# Retired and Out-of-Scope Components

This document records scripts and modules that are intentionally retired or excluded from the OpenMemo open-source product scope.

## Excluded Components

- **`pull_inbox.py`**: Private inbox pulling and personal sync pipeline. Out of open-source scope.
- **Retired Bookmark Importer**: Deprecated bookmark archive ingestion utilities. Out of open-source scope.

## Scope Boundary

OpenMemo focuses on core vault structure, multi-hop knowledge graph schemas, associative memory indexing, and the Model Context Protocol (MCP) server integration. Personal sync adapters, private life OS integrations, and legacy one-off import pipelines remain outside the public repository boundary.
